# NexusAI Lite — Free SaaS Landing Page Starter

A free, simple frontend sample derived from the NexusAI Pro design.

## Included
- `index.html` — responsive hero, two feature cards, Pro information banner
- `styles.css` — custom dark theme, responsive layout
- `script.js` — mobile navigation only

## Use
1. Unzip the folder.
2. Open `index.html` in a browser.
3. Edit branding, headlines and links in `index.html`.
4. Edit colors/layout in `styles.css`.
5. Upload these three website files to an appropriate static host.

No installation, account, backend, or payment integration is required.

## Lite vs Pro
Pro adds a full interactive dashboard, six feature cards, how-it-works, pricing toggle, FAQ, and additional CTA content. These are **not** part of the Lite package.

## Before publishing on GitHub
- Review and choose a LICENSE for the code. This bundle does not grant a license to third parties by default.
- Replace example brand/copy with your own authorized content where necessary.
- Add an actual Pro-store URL only once your verified product listing exists.
- Test on mobile and desktop. No sales or traffic are guaranteed.
